## 主要風險

1. 開發環境是 Linux，無法編譯與執行 Windows 桌面程式。elf-core 與前端可在此完整測試，Tauri 外殼與 Windows API 只能在使用者電腦驗證。G2 是全案最大的不確定點，排在 D3 就是為了留四天緩衝。
2. 習慣建議需要至少 5 個工作日的真實資料，一週內只能以事件回放驗證規則，不能驗證建議是否真的有用。
3. 多個開發 Agent 平行時的介面漂移，以 D1 介面凍結與單一型別來源控制。
