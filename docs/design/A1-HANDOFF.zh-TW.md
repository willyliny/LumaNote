## 三個角色方向

character-concepts.png 使用內建 imagegen 產生，保留為視覺探索；正式候選 SVG 是程式化幾何重繪，有意簡化材質與陰影，並非點陣圖自動向量化。避免將概念圖直接縮成 16 px 圖示。

## 狀態與互動規格

| 狀態 | 不依賴顏色的辨識 | 動態規格建議 | 顯示文字 |
| --- | --- | --- | --- |
| 待命 | 基本輪廓，雙眼睜開 | 靜止 | 隨時可以交辦 |
| 聆聽輸入 | 左右張開弧線 | 僅輸入聚焦時淡入；不是持續麥克風監聽 | 正在接收輸入 |
| 處理中 | 上方循環箭頭 | 1800 ms 緩慢循環，角色本體不跳動 | 正在處理，可停止 |
| 等待確認 | 方形驚嘆號標記 | 靜止；不閃爍、不搶焦點 | 需要你確認 |
| 有建議 | 葉尖旁十字星標記 | 首次出現淡入一次，之後靜止 | 有一則建議 |
| 勿擾或暫停 | 閉眼、雙直線暫停標記 | 靜止 | 文字分別顯示勿擾或觀察已暫停 |

勿擾和暫停觀察可共用角色圖，但產品狀態與設定不可合併。角色徽章只傳達概況；tooltip 與可讀名稱需給出完整狀態。深色背景上的狀態符號應使用淺色前景或中性底板，不能只把深綠線條直接放在深色桌布。

浮動入口 64 × 64 CSS px，可拖曳；貼邊收合可視範圍 12 × 48 px。收合時命中區向內擴至 44 px，實作須驗證不攔截無關桌面區域；另保留全域快捷鍵與系統匣入口。提示最多兩行，禁止自動開大面板或取得鍵盤焦點。

減少動態偏好啟用時禁用循環、位移與縮放，只保留靜態狀態。圖示應搭配 aria-label；串流回覆不要逐字觸發讀屏播報。授權卡不得預設鍵盤焦點於核准按鈕，拒絕與關閉皆需可操作。

PNG 是完整內容的設計展示，不代表桌面視窗固定使用該高度。實作以可用工作區高度限制視窗，標題與輸入區固定，內容區捲動；200% 縮放及 380 px 寬仍需整合測試。進度條僅在後端有實際可計算進度時使用；否則用不定進度與步驟文字，不顯示虛構百分比。

## 字體

建議 Noto Sans TC 或 Noto Sans CJK TC，支援繁體中文；後備為系統 Microsoft JhengHei UI，最後 sans-serif。示意頁優先使用本機已安裝的 Noto Sans TC，不打包 Windows 字體。

Noto CJK 採 SIL Open Font License 1.1，可隨商用軟體嵌入與散布，但需保留版權及授權文字，不可單獨販售字體；修改版本另須遵守保留名稱規定。[官方字體授權](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)，查閱日期 2026/11/11。正式打包時請核對實際採用字體檔的授權並附入安裝包。

## 給前端與技術負責人

1. design-tokens.json 為交付資料；design-tokens.css 提供可直接匯入的色彩變數與基本尺寸。其他尺寸以 JSON 為準，統一轉入前端單一 token 檔。
2. 套用 `.panel[data-theme="dark"]` 或根節點 data-theme 切換深色。請保持語意色名稱，不在元件中硬寫 hex。
3. SVG 適合一般 UI，16 px 系統匣使用專用單色版；系統匣使用哪個顏色依實際背景決定。
4. 模型供應商仍由設定資料驅動，品牌與介面不綁某家 AI；示意稿沒有放供應商品牌。
5. 「保留修改前版本」是授權卡的示例文案；只有後端實際建立備份時才顯示。所有檔名、修改行數與操作影響均須由已驗證工具計畫填入。
6. 目前沒有 React 元件、IPC 接線、可操作的待辦或動畫成品，這些屬於 F2／T1。勿把靜態示意當成已完成產品功能。
7. D4 定稿需要選 A／B／C；選定後統一角色狀態、圖示及設計 token，並在實際 Tauri 視窗與任務列驗證。
