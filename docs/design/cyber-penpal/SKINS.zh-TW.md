## 切換流程設計

入口：設定 → 外觀 → 助手造型。三張選擇卡呈現角色、名稱與「目前使用」標記；點選可預覽，再按「套用造型」。預覽不寫入偏好，套用後立即更新桌面入口與聊天頭像，並持久化選擇。提供還原預設夜航。

造型只影響外觀，不更換 AI 供應商、模型、語氣設定、記憶、任務、工具權限或通知規則。執行中的任務不因切換重新開始。產品應用程式圖示維持固定品牌，系統匣是否跟隨造型可作後續選項，第一版維持固定。

建議偏好欄位為 appearance.skin_id；此為提案，由核心／前端負責人接入既有 settings 契約，未在此改動 IPC。素材清單應由本機可信 manifest 管理，不以使用者輸入任意路徑載入內容。未知 ID 或載入失敗時回退 night-letter 並保留可用介面。

每款正式素材需對應 idle、listening、processing、approval、suggestion、paused 六種相同語意狀態。畫面中的三個小圖僅展示待命、處理與等待回覆；等待回覆的信件標記不可直接視為高風險操作授權提示，approval 需另有明確標記與文字。

## 素材定稿前工作

1. 三款各自製作透明背景的獨立素材與六種狀態，統一畫布、錨點及顯示尺寸，避免切換時跳位。
2. 48 px 保留眼睛與主要輪廓，減少細光帶；96 px 可呈現材質。深淺桌布都需驗證。
3. 動畫只作用於環軌、頁片或局部光感，不改變桌面命中區；減少動態模式使用靜態圖。
4. 製作外觀選擇頁及鍵盤選擇、讀屏名稱；選中卡片同時有勾號與文字。
5. 驗證套用、取消預覽、重啟保留、素材遺失回退，以及任務執行中切換不影響任務狀態。
