# 風格圖簡報（給 GPT-6 Astra）

產品：LumaNote，Windows 11 桌面 AI 個人助理。使用者把事情交給它處理，它查清楚、執行、回報，需要使用者決定時會明說。常駐在桌面邊緣的是一個小精靈浮動入口。

## 要傳達的感覺

可靠、安靜、有分寸。它是幫你把事情做完的助手，不是吵著要注意力的寵物，也不是冷冰冰的企業工具。主動建議時像同事輕聲提醒，不打斷工作。

避免：誇張的賽博龐克霓虹、過度可愛的幼兒風、擬真 3D 人形、任何現有作品或品牌角色的造型。角色必須是原創。

## 交付清單

1. 精靈角色設定，三個方向供選（D2），選定後定稿一個（D4）。
   - 需在 48×48 與 96×96 像素下仍可辨識，輪廓簡潔。
   - 透明背景，要能放在任何桌布上；請同時給淺色與深色桌布的示意。
2. 六種狀態：待命、聆聽輸入、處理中、等待使用者確認、有建議（低調）、勿擾或暫停觀察。狀態差異要靠形狀或姿態區分，不能只靠顏色。
3. 色彩系統：主色、輔色、成功、警告、錯誤、中性灰階，淺色與深色主題各一組，附色碼。文字與背景對比至少 4.5:1。
4. 介面風格示意圖三張：
   - 對話面板（串流回覆、來源引用、附件、停止按鈕）
   - 任務卡與授權確認卡（顯示將執行的操作、對象、後果，以及核准與拒絕）
   - 今日面板（待辦、行程、提醒、一則主動建議卡）
5. 應用程式圖示：16、32、48、256 像素版本，以及系統匣用的單色版本。
6. 字體建議：需支援繁體中文，註明授權可商用。

## 交付格式

角色與圖示給 SVG 與 PNG；示意圖給 PNG，寬 1600 像素以上。色彩與間距、圓角請以表格列出數值，前端會直接轉成設計 token。

## 介面限制

- 浮動入口可拖曳、可貼邊收合成一小條，收合狀態也要設計。
- 主動建議以浮動入口旁的小提示呈現，不搶焦點，不跳大視窗。
- 面板為桌面小視窗，寬約 380 至 480 像素，非全螢幕網頁。
