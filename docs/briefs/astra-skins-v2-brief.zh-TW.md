## 硬性要求

1. **背景必須真正透明。** 概念圖把角色畫在深藍底上，不能直接使用。浮動入口是放在使用者桌布上的透明視窗，任何底色都會變成一個方塊。
2. **48 像素下要認得出來。** 夜航系列的發光、半透明、細線在小尺寸會糊掉，請另外畫簡化版：實心色塊為主，最多一層外發光，線寬在 48 像素下不小於 2 像素。可以另附一張大尺寸的精緻版作為設定頁預覽用（`preview.png`，512 像素）。
3. **淺色與深色桌布都要看得見。** 夜航系列在淺色桌布上、葉披風等在深色桌布上都要檢查；需要時加一圈對比輪廓。請附每款在淺色、深色桌布上的示意。
4. **六種狀態靠形狀或姿態區分，不能只靠顏色。** 六種狀態的意義：待命、聆聽輸入（輸入框取得焦點）、處理中、等待使用者確認、有建議（低調）、勿擾或暫停觀察。
5. **同一款的六種狀態，角色本體的位置與大小要一致**，切換狀態時不能跳動。畫布統一 96 × 96，角色置中，四周至少留 8 像素給狀態標記。
6. **SVG 內不要嵌入點陣圖**，不要使用外部字體或外部連結。濾鏡（發光）可以用，但請控制在一到兩個。
7. **全部原創**，不參考任何現有作品或品牌角色。

## skin.json 格式

```json
{
  "id": "night-letter",
  "name": "夜航",
  "family": "night-voyage",
  "preferredTheme": "dark",
  "accent": { "light": "#000000", "dark": "#000000" },
  "onAccent": { "light": "#000000", "dark": "#000000" },
  "glow": "#000000"
}
```

- `family`：葉披風、月環石、紙燈填 `quiet-desk`；夜航三款填 `night-voyage`。
- `preferredTheme`：這款造型最適合的主題，`light` 或 `dark`。
- `accent`、`onAccent`：切到這款造型時，介面主要按鈕的顏色與其上的文字顏色，淺色與深色主題各一。文字與底色對比至少 4.5:1，請附量測值。
- `glow`：角色外發光的顏色，沒有就省略。

## 夜航系列的介面配色

請另外交付一份 `docs/design/skins/night-voyage-tokens.json`，欄位與現有的 `design-tokens.json` 完全相同（canvas、surface、subtle、text、muted、primary、onPrimary、secondary、success、warning、error、border、focus，淺色與深色各一組）。夜航以深色為主，但淺色主題也必須可用。所有文字色對三種背景的對比至少 4.5:1，附對比報告。
