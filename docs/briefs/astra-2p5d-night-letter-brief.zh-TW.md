# 夜航 2.5D 樣品簡報（給 GPT-6 Astra）

日期：2026/11/12　範圍：只做 night-letter（夜航）一款，靜態定稿加待命動態。確認桌面上的質感後再延伸到其他五款與其他狀態。

方向已與使用者確認：固定微側視角，呈現玻璃厚度、透光與反射；素材分層；輕量動態；透明背景。前端以透明圖片分層加 CSS 動畫實作，暫不使用 Canvas 或 WebGL。

## 交付位置與檔案

放在 `docs/design/skins/night-letter/layered/`。現有的平面版（idle.svg 等）保留不動，作為降級與小尺寸使用。

| 檔案 | 內容 |
| --- | --- |
| `layers.json` | 圖層清單，格式見下 |
| 各圖層圖檔 | 透明背景 PNG 或 WebP，每層各有 `@1x`（192 像素）與 `@2x`（384 像素）兩種，例如 `body@1x.png`、`body@2x.png` |
| `composite.png` | 所有圖層疊好的靜態定稿，384 像素，透明背景，供驗收比對 |
| `on-light.png`、`on-dark.png` | 在淺色與深色桌布上、96 像素實際大小的示意 |

## 圖層

所有圖層使用**同一張正方形畫布、同一個原點**，直接疊在一起就是完整角色，前端不需要另外對位。畫布四周留至少 12% 的空白給光暈與漂浮位移，角色不可貼邊。

夜航建議的圖層，由下到上：

| 圖層 ID | 內容 | 前端會做的動態 |
| --- | --- | --- |
| `shadow` | 落在桌面上的柔和陰影 | 隨漂浮略微縮放與變淡 |
| `glow` | 外發光，已模糊處理好的圖 | 緩慢明暗 |
| `body-back` | 信封背面與側邊厚度 | 隨本體移動 |
| `body` | 信封正面、透光與反射 | 漂浮、微幅傾斜 |
| `highlight` | 玻璃高光 | 傾斜時反向微移，製造反射感 |
| `eyes-open` | 睜眼 | 眨眼時隱藏 |
| `eyes-closed` | 閉眼 | 眨眼時顯示 |
| `pen` | 筆尖 | 可比本體略晚跟上，製造層次 |

可以增減圖層，但請遵守下面的限制。

## 硬性限制

1. **光暈與模糊請直接畫進圖裡**，不要依賴前端做模糊濾鏡。常駐桌面的視窗持續做即時模糊會吃顯示卡。
2. **前端只會做位移、旋轉、縮放、透明度四種變化。** 需要形變的效果（例如書頁翻開）請用「兩張圖交叉淡入」能表現的方式設計，或先不做。
3. **圖層最多 8 層**，全部圖檔合計不超過 600 KB（`@1x` 加 `@2x`）。
4. **邊緣要乾淨。** 半透明邊緣不可帶深藍或白色雜邊，放在任何顏色的桌布上都不能出現一圈色邊。請在純白、純黑、鮮豔色三種背景上檢查。
5. **96 像素下要清楚。** 預設顯示約 96 像素，眼睛與輪廓在這個大小必須一眼可辨。48 像素以下前端會改用現有的平面版，不需要為小尺寸妥協。
6. **閉眼圖層只改眼睛**，其他部分與睜眼時完全一致。
7. 淺色桌布上若輪廓不夠清楚，請在 `body-back` 或另加一層細輪廓解決，不要把整體調暗。
8. 全部原創。

## layers.json 格式

```json
{
  "id": "night-letter",
  "canvas": 384,
  "layers": [
    { "id": "shadow", "file": "shadow", "role": "shadow" },
    { "id": "glow", "file": "glow", "role": "glow" },
    { "id": "body-back", "file": "body-back", "role": "body" },
    { "id": "body", "file": "body", "role": "body" },
    { "id": "highlight", "file": "highlight", "role": "highlight" },
    { "id": "eyes-open", "file": "eyes-open", "role": "eyes-open" },
    { "id": "eyes-closed", "file": "eyes-closed", "role": "eyes-closed" },
    { "id": "pen", "file": "pen", "role": "accessory" }
  ],
  "pivot": { "x": 0.5, "y": 0.62 }
}
```

- `file` 不含尺寸與副檔名，前端會自動接上 `@1x.png` 或 `@2x.png`（WebP 請註明）。
- `role` 決定前端套用哪一種動態，請只用上表列出的值；`accessory` 可以有多個。
- `pivot` 是傾斜時的旋轉中心，以畫布比例表示，通常在角色重心略偏下。

## 動態（由前端實作，這裡說明以便設計時配合）

- 漂浮：上下約 3 像素，週期約 4 秒。
- 眨眼：每 4 到 7 秒隨機一次，約 0.15 秒。
- 傾斜：滑鼠靠近或拖曳時最多約 4 度。
- 使用者開啟「減少動態」時全部靜止，只顯示 `composite` 的效果，所以靜態定稿本身就要好看。
- 視窗不可見或閒置一段時間後動畫會暫停。

## 這次不做

其他五種狀態、其他五款造型、星軌旋轉與書頁開合。夜航樣品在實際桌面上確認後，再依同樣格式擴充；屆時狀態標記會是獨立的 `state-<名稱>` 圖層疊在最上面。
